# 让提醒像「微信消息」一样进来（企业微信自建应用 + 微信插件）

先说清楚：**个人微信没有开放的发消息接口**，任何声称能直接给你个人号发消息的第三方库
（itchat / wechaty 之类）都是逆向协议，有封号风险，不建议用。

合规又能"像聊天消息"的做法只有一个：**企业微信自建应用**，再用「微信插件」把它接到个人微信。
接好之后，你会在微信聊天列表里看到一个以**企业简称**命名的会话，新消息有红点，和好友消息一样。

---

## 一、拿三个参数（约 10 分钟，一次性）

1. **注册企业微信**：打开 <https://work.weixin.qq.com/> → 立即注册 → 填手机号和企业名称
   （个人也能注册，名字随便填，比如「Philip 的学习小组」，不认证也能用自建应用）。
2. **拿企业 ID**：管理后台 →「我的企业」→「企业信息」→ 最下面 **企业ID**，形如 `ww1234567890abcdef`。
3. **建自建应用**：管理后台 →「应用管理」→「应用」→ 自建 → **创建应用**
   - 名称：`单词复习`
   - 可见范围：勾上你自己
   - 创建完进去，拿到 **AgentId**（一串数字）和 **Secret**（点"查看"）。
4. **打开微信插件**（关键一步）：「我的企业」→「微信插件」→ 页面里有个二维码 →
   **用你的个人微信扫码关注**。关注后，应用消息就会出现在个人微信里。

## 二、本地测一条

```powershell
.\vv.cmd push --format wecom-app `
    --corpid "ww123..." --secret "你的Secret" --agentid 1000002 --touser "@all"
```

成功会打印 `✓ 已推送到企业微信（微信插件）`，微信里立刻能看到。

想把参数存下来、不用每次敲，最简单的办法是把 `notify.cmd` 改成：

```bat
@echo off
set WECOM_CORPID=ww123...
set WECOM_SECRET=...
set WECOM_AGENTID=1000002
set WECOM_TOUSER=@all
call "%~dp0vv.cmd" push --format wecom-app --title "今日单词复习"
```

`vocabcurve push --format wecom-app` 会自动读 `WECOM_*` 环境变量。`notify.cmd` 已经在
`.gitignore` 里，不会被推到 GitHub。

## 三、云端：电脑关机也能发

企业微信接口就是两个 HTTPS 请求，任何能跑定时任务的云端都行。用 GitHub Actions 的话：

1. 建私有仓库，把本目录推上去（`.\setup-cloud.ps1 -RepoUrl "..."`）。
2. 仓库 Settings → Secrets → Actions，加四个：
   `WECOM_CORPID` / `WECOM_SECRET` / `WECOM_AGENTID` / `WECOM_TOUSER`
3. Actions 页手动 Run 一次；成功之后每天北京时间 07:25 自动跑。

> 企业微信对自建应用发消息有频率限制（每分钟几百条），一天一条完全没问题。

## 四、不想注册企业微信的替代方案

| 方案 | 消息长什么样 | 代价 |
| --- | --- | --- |
| 企业微信群机器人 | 企业微信群里的一条文本消息（像群聊） | 3 分钟，但要在企业微信 App 里看 |
| Server酱 | 服务号推送卡片 | 你已经说不喜欢了 |
| ntfy | 另一个 App 的通知 | 要装 App |

如果只是"不想看服务号卡片、想要普通聊天消息"，**企业微信自建应用 + 微信插件**是目前唯一合规的选择。
